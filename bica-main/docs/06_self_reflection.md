# BICA: независимая саморефлексия и аудит визуальных доказательств

Статус: прототип, 17.11.2026. **Результативность нового метода на реальной VLM ещё не измерена.** Не путать успешный запуск, корректный JSON и правильное распознавание.

## Задача, согласованная командой

Создать воспроизводимого агента на основе существующей визуально-языковой модели (VLM), который лучше распознаёт действительно разные трактовки неоднозначных изображений, но не становится более внушаемым по отношению к неверным текстовым подсказкам. Условие честного успеха — одновременный рост обнаружения подтверждённых вторых интерпретаций и контроль ложных альтернатив на обычных изображениях.

Это **агентная система с управляемыми вызовами VLM**. Она не является обученной с нуля нейросетью и не содержит обученных нами весов. Не выдавать использование готовой VLM и промптов за fine-tuning.

## Архитектура v0.2

```text
                   ┌──────────────────────┐
Оригинал + cue ────>│ 1. Initial reading   │───┐
                   └──────────────────────┘   │
                                              ├──> 3. Evidence adjudicator --> JSON
Оригинал ─────────>┌──────────────────────┐   │         ↑
(без cue, без шага 1)│ 2. Blind reading     │───┘         │
                   └──────────────────────┘           │
                                                     │
reflect_zoom: 1–2 crops из областей evidence ────────┘
```

### Точный протокол

- `reflect` — три независимых обращения к одной VLM (при одной и той же исходной модели). 1) Свободное описание, предложенная текстовая интерпретация считается недоверенной. 2) **Новый диалог без истории первого вызова и без подсказки**, специальный анализ контуров, негативного пространства и фигура/фон; seed второй попытки детерминированно сдвинут. 3) Новый диалог с исходной картинкой и двумя структурированными ответами; модель-аудитор проверяет визуальные основания, различает синонимы и реально разные трактовки, ставит статусы и отвечает на исходную подсказку.
- `reflect_zoom` — те же три обращения, но на последнем шаге добавляются до двух увеличенных вырезок 60%×60% исходного изображения; области выбираются **по описаниям мест признаков в первых двух ответах**, без чтения эталонов. Всегда передаётся и полная картинка; вырезки не считаются независимыми подтверждениями. Требует Pillow (`pip install Pillow`).
- `direct`, `repeat`, `hypotheses`, `evidence` — сохранены без изменения схемы эксперимента как внутренние базовые режимы и абляции.

Все режимы используют общий структурированный ответ из `illusion_agent/prompts/system.txt`. Вторая ветвь не видит слова/разметку исходного cue; финальный арбитр снова получает cue, маркированное как недоверенное. Генеративные результаты проверяются по синтаксису, но структура ответа **не доказывает** правильность признаков.

Логируются все запросы и ответы, хеш оригинала, хеши дополнительных изображений, координаты вырезок, время, usage и лексические диагностические флаги. `label_disagreement` — **несовпадение строк поддержанных названий**, а не автоматическая оценка семантической правильности: синонимы могут дать ложное срабатывание. Основная оценка — у независимых людей.

## Запуск на реальной модели

Локальный тест всех шести режимов на шести отладочных изображениях, только нейтральный cue, 96 вызовов (6 × (1 + 3 + 3 + 3 + 3 + 3)):

```bash
python -m unittest discover -s tests -v
python -m illusion_agent run --manifest data/ambibench_debug/manifest.jsonl --modes direct,repeat,hypotheses,evidence,reflect,reflect_zoom --max-calls 96 --dry-run
python -m illusion_agent run --manifest data/ambibench_debug/manifest.jsonl --provider ollama --model YOUR_VISION_MODEL --modes direct,repeat,hypotheses,evidence,reflect,reflect_zoom --max-calls 96 --output runs/real_v02
python -m illusion_agent diagnostics --run runs/real_v02 --output runs/real_v02/diagnostics.json
```

Вместо локального Ollama на ПК можно использовать `notebooks/self_reflection_colab.ipynb` в Google Colab, архив `deliverables/bica_colab_bundle.zip` и доступную GPU. Дата создания экспериментальной папки, точная ревизия модели, seed, копии изображений и промптов должны сохраняться. Если менять код, модель или промпты, использовать **новую папку**. Старый пилот v1 не смешивать с v0.2.

**Важно:** архив картинок был восстановлен из вложенного исходного `deliverables/bica_colab_bundle.zip`, потому что в исходном `bica-main.zip` файлов `data/ambibench_debug/images/` не было. Контроль SHA-256 при загрузке манифеста остаётся обязательным.

## Оценка после реального запуска

1. Подготовить дополнительную отложенную выборку неоднозначных, обычных и (по желанию) абстрактных изображений. Два человека независимо размечают допустимые интерпретации, признаки и истинность заранее подготовленных подсказок. Отладочные 6 изображений не включать в подтверждающий тест.
2. По одному изображению предъявлять нейтральное условие, истинную и ложную подсказку как **разные случаи без общей истории**. Сравнивать режимы на одних и тех же изображениях и условиях.
3. После выполнения `export-review` выдавать двум оценщикам слепые пакеты `packets.json` и `ratings.csv`, но **не** файл `*_mapping.json` с именами методов. Согласовать оценки и только затем переводить `review_status` в `adjudicated`.
4. Выполнить `score` для долей и `paired-score` для парного сравнения двух методов с доверительным интервалом, пересэмплируя **оригинальные изображения**, а не отдельные ответы. Для `false_alternative` технически упавшие пары исключаются с явным указанием числа; ошибки всегда показывать отдельно.
5. Учитывать дополнительные визуальные токены режима `reflect_zoom`; равенство числа VLM-вызовов **не означает** равных затрат. Показывать время и токены. Не выдавать неподтверждённую тенденцию за статистически доказанный результат.

```bash
python -m illusion_agent export-review --run runs/real_v02 --manifest data/ambibench_debug/manifest.jsonl --output reviews/a
# После реальной слепой разметки и согласования аннотаций:
python -m illusion_agent score --run runs/real_v02 --mapping runs/real_v02/a_mapping.json --ratings reviews/a/ratings_consensus.csv --annotations data/ambibench_debug/annotations.jsonl --output reports/real_v02_rates.json
python -m illusion_agent paired-score --run runs/real_v02 --mapping runs/real_v02/a_mapping.json --ratings reviews/a/ratings_consensus.csv --annotations data/ambibench_debug/annotations.jsonl --baseline direct --candidate reflect --metric both_valid --output reports/paired_both_valid.json
```

## Абляции и исследовательские гипотезы

- H1: `reflect` превосходит `repeat` и `evidence` по обнаружению двух истинных трактовок при сопоставимой устойчивости к ложным cue.
- H2: `reflect_zoom` исправляет ошибки, связанные с локальным пропуском признаков, но не повышает долю неподтверждённых альтернатив и не становится слишком дорогим.
- H3: независимый слепой проход снижает якорение на исходной текстовой подсказке. Проверяется отдельно на истинных и заведомо ложных cue.

Проверять не только средние баллы, но и **случаи ухудшения**, согласие оценщиков, ошибку восприятия, форматы ответов, токены и задержку. При недостаточной мощности выборки писать «наблюдается тенденция», а не «доказано».

## Принципиальные ограничения

1. Саморефлексия в данном коде не является моделью с новыми весами; финальная оценка производится той же VLM, что создаёт гипотезы. Это может воспроизводить её ошибки. Два человеческих оценщика необходимы.
2. Детектор лексических расхождений не распознаёт смысловые синонимы, а простой ROI-парсер ориентирован на английские географические указания `top`, `left`, `center` и т. п. Для других языков ROI может перейти к центральной области.
3. `reflect_zoom` меняет фактический визуальный бюджет и не может считаться строго идентичным `reflect` по вычислительным ресурсам.
4. Шесть отладочных изображений из текущего архива не дают публикационной оценки. В `annotations.jsonl` статус разметки первоначально не согласован.
5. Внешние SOTA-агенты (например, Visual Sketchpad) и оригинальные официальные протоколы AmbiBench/IllusionBench **не воспроизведены**. Внутренние четыре baseline-режима нельзя выдавать за SOTA.
