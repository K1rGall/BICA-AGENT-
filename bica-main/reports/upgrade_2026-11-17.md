# BICA v0.2: отчёт об обновлении — 17 ноября 2026

## Реализовано

1. Добавлены агентные режимы `reflect` и `reflect_zoom`: второй независимый анализ не видит исходный текстовый cue или первый ответ, третий шаг получает оба структурированных анализа и повторно проверяет полную картинку.
2. Добавлена локальная обработка визуальных регионов (выбор до двух ROI с координатами и хешами); изображения всегда сохраняются без эталонов.
3. Добавлены лёгкие диагностические флаги о различии гипотез без утверждений о визуальной правильности.
4. Добавлена команда `diagnostics` для технических параметров и `paired-score` для сравнения оцененных ответов с cluster bootstrap по оригиналам.
5. Манифест теперь запрещает путь изображения за пределы собственного каталога.
6. Восстановлены 6 изображений из вложенного оригинального Colab ZIP, проверяются по SHA-256.
7. Добавлены тесты нового поведения, Colab ноутбук и GitHub Actions workflow.

## Что действительно проверено локально

- `python -m unittest discover -s tests -q`: **34 теста, все пройдены**.
- `python -m illusion_agent run ... --dry-run` для всех 6 режимов и 6 картинок: **36 случаев, 96 плановых вызовов**.
- Полный synthetic/mock-проход 36/36 случаев с 0 технических ошибок, журналирование и техническая статистика `diagnostics` успешно завершены.
- В реальном пилоте Qwen из старых материалов было 24 случая, 12 технических ошибок; этот запуск не использует обновлённый код и не подтверждает преимущество нового агента.

**Ограничение:** здесь не запускалась настоящая VLM на GPU, не выполнялась слепая оценка, не получены показатели распознавания и статистической значимости. Mock всегда возвращает неопределённость; его успех подтверждает только проводку пайплайна.

## Что требуется перед защитой

- Запустить все режимы на той же ревизии одной VLM (Google Colab с GPU или локальный Ollama); сохранить полный trace и конфигурацию.
- Разметить изображения и подсказки с двумя независимыми оценщиками; пополнить нормальные отрицательные примеры и новый отложенный набор.
- Рассчитать `both_valid`, `false_alternative`, `cue_correct`, `grounded`, ошибки, токены и paired bootstrap CI.
- Указать использованную оригинальную статью/бенчмарк, различать собственный агент и существующий backbone.
- Если требования подразумевают published SOTA, добавить независимые опубликованные агентные baseline; текущий репозиторий их не содержит.
